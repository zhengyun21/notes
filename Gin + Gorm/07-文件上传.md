## 一、单文件
1. 方式
	1. `c.FormFile` 从 `multipart/form-data` 请求中接收 **单个上传** 的文件
	2. `c.SaveUploadedFile` 将其保存到磁盘。
	3. 设置 `router.MaxMultipartMemory` 来控制 multipart 解析期间使用的最大内存（默认为 32 MiB）。超过此限制的文件将存储在磁盘上的临时文件中而不是内存中。
2. 示例
	1. ``` go
		router.MaxMultipartMemory = 8 << 20 // 8 MiB
		r.POST("/upload/single", func(c *gin.Context) {  
		    file, err := c.FormFile("file")  
		    if err != nil {  
		       c.JSON(http.StatusBadRequest, gin.H{  
		          "message": err.Error(),  
		       })  
		       return  
		    }  
		    dst := filepath.Join("./test-files/", filepath.Base(file.Filename)) //获取保存地址 ，没有目录会自动创建
		    err = c.SaveUploadedFile(file, dst)  
		    if err != nil {  
		       c.JSON(http.StatusBadRequest, gin.H{  
		          "message": err.Error(),  
			    })  
		       return  
		    }  
		    c.JSON(http.StatusOK, gin.H{  
		       "message": "ok",  
		    })  
		})
	   ```

## 二、多文件
1. 方式
	1. `c.MultipartForm` 接收在单个请求中上传的多个文件。文件按表单字段名分组——对所有要一起上传的文件使用相同的字段名。
2. 示例
	1. ``` go
		r.POST("/upload/multi", func(c *gin.Context) {  
		    form, err := c.MultipartForm()  
		    if err != nil {  
		       c.String(400, err.Error())  
		       return  
		    }  
		    files := form.File["files"]  
		    for _, file := range files {  
		       log.Println(file.Filename)  
		       // 注意路径的写法
		       dst := filepath.Join("./test-files/", filepath.Base(file.Filename))
		       err := c.SaveUploadedFile(file, dst)  
		       if err != nil {  
		          c.JSON(400, gin.H{  
		             "message": "failed",  
		          })  
		          return  
		       }  
		    }  
		    c.String(200, "OK")  
		})
	   ```
