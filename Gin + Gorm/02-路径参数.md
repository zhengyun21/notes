1. **`:name`** —— 匹配单个路径段。例如，`/user/:name` 匹配 `/user/john`，但**不**匹配 `/user/` 或 `/user`。
	1. 示例
		1. ``` go
		r.GET("/user/:name", func(context *gin.Context) {  
		    name := context.Param("name")  
		    fmt.Println(name)  
		    context.String(http.StatusOK, "hello %s", name)  //输出 hello {name}}
		})  
  
		r.GET("/user/:name", func(context *gin.Context) {  
		    name := context.Param("name")  
		    fmt.Println(name)  
		    context.JSON(http.StatusOK, gin.H{  
		       "message": name,  
		    })  //输出 {"message": {name}}
		})
		   ```
1. **`*action`** —— 匹配前缀之后的所有内容，包括斜杠。例如，`/user/:name/*action` 匹配 `/user/john/send` 和 `/user/john/`。捕获的值包含前导 `/`。
	1. 示例
		1. ``` Go
		   r.GET("/user/:name/*action", func(context *gin.Context) {  
		    name := context.Param("name")  
		    fmt.Println(name)  
  
		    action := context.Param("action")  
		    fmt.Println(action)  
  
		    context.String(http.StatusOK, "hello %s %s", name, action)  
		})  
		   ```
**注意**：
1. 通配符 `*action` 的值始终包含前导 `/`。在上面的示例中，`c.Param("action")` 返回 `/send`，而不是 `send`。
2. 如果 `/user/:name` 和 `/user/:name/*action` 在相同路径深度产生冲突，则不能同时定义它们。如果 Gin 检测到歧义路由，将在启动时 panic。
