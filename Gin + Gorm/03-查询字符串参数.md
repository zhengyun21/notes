1. 查询字符串参数是出现在 URL 中 `?` 后面的键值对（例如 `/search?q=gin&page=2`）
2. 两种方式查询：
	1. `c.Query("key")` 返回查询参数的值，如果 **key** 不存在则返回**空字符串**。
	2. `c.DefaultQuery("key", "default")` 返回值，如果 **key**不存在则返回函数后面指定的 **默认值**。
3. 示例
   ``` Go
		r.GET("/welcome", func(context *gin.Context) {  
		    guest := context.Query("guest")  
		    sex := context.DefaultQuery("sex", "unknown")  
		    context.String(http.StatusOK, "hello %s, you are %s", guest, sex)  
		})
   ```
