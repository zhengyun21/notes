## 1. 日志概述

Gin 内置日志中间件记录每个 HTTP 请求的：状态码、HTTP 方法、路径、延迟。

- 使用 `gin.Default()` 会自动附加 Logger + Recovery 中间件
- 使用 `gin.New()` + `r.Use(gin.Logger())` 可手动控制
- 默认输出到 `os.Stdout`，格式：

```
[GIN] 2025/06/01 - 15:04:05 | 200 | 512.345µs | 127.0.0.1 | GET "/ping"
```

---

## 2. 如何写入日志文件

通过设置 `gin.DefaultWriter` 重定向日志输出。

```go
// 禁用控制台颜色（写文件时不需要）
gin.DisableConsoleColor()

// 写入单一文件
f, _ := os.Create("gin.log")
gin.DefaultWriter = io.MultiWriter(f)

// 同时写入文件和控制台（开发时常用）
// gin.DefaultWriter = io.MultiWriter(f, os.Stdout)

router := gin.Default()
router.Run(":8080")
```

### 生产环境日志轮转

使用 [lumberjack](https://github.com/natefinch/lumberjack) 实现按大小/时间轮转：

```go
import "gopkg.in/natefinch/lumberjack.v2"

gin.DefaultWriter = &lumberjack.Logger{
    Filename:   "gin.log",
    MaxSize:    100,  // 单文件最大 MB
    MaxBackups: 3,    // 保留旧文件数量
    MaxAge:     28,   // 旧文件保留天数
}
```

## 3. 自定义日志格式

使用 `LoggerWithFormatter` 替换默认日志格式：

```go
router.Use(gin.LoggerWithFormatter(func(param gin.LogFormatterParams) string {
    return fmt.Sprintf("%s - [%s] \"%s %s %s %d %s \"%s\" %s\"\n",
        param.ClientIP,
        param.TimeStamp.Format(time.RFC1123),
        param.Method,
        param.Path,
        param.Request.Proto,
        param.StatusCode,
        param.Latency,
        param.Request.UserAgent(),
        param.ErrorMessage,
    )
}))
```

`gin.LogFormatterParams` 可用字段：`ClientIP`、`TimeStamp`、`Method`、`Path`、`Request`、`StatusCode`、`Latency`、`ErrorMessage` 等。

## 4. 跳过日志记录

使用 `LoggerConfig` 的 `SkipPaths` 和 `Skip` 字段：

```go
loggerConfig := gin.LoggerConfig{
    // 按路径跳过（如健康检查、指标端点）
    SkipPaths: []string{"/metrics", "/health"},
    // 按自定义逻辑跳过
    Skip: func(c *gin.Context) bool {
        return c.Writer.Status() < http.StatusInternalServerError
    },
}
router.Use(gin.LoggerWithConfig(loggerConfig))
```

## 5. 控制日志输出着色

```go
// 禁用着色（写文件时使用）
gin.DisableConsoleColor()

// 强制启用着色（非 TTY 环境）

```

默认根据 TTY 自动检测。

## 6. 避免记录查询字符串

查询字符串可能包含敏感信息（API 令牌、密码、会话 ID、PII）。

```go
loggerConfig := gin.LoggerConfig{
    SkipQueryString: true,
}
router.Use(gin.LoggerWithConfig(loggerConfig))
```

启用后 `/search?q=gin&token=secret` 只记录为 `/search`。应用逻辑不受影响，`c.Query()` 仍可正常获取参数。

## 7. 定义路由日志格式

Gin 启动时在调试模式打印路由，默认格式：

```
[GIN-debug] GET  /ping     --> main.main.func1 (3 handlers)
```

通过 `gin.DebugPrintRouteFunc` 自定义：

```go
gin.DebugPrintRouteFunc = func(httpMethod, absolutePath, handlerName string, nuHandlers int) {
    log.Printf("endpoint %v %v %v %v\n", httpMethod, absolutePath, handlerName, nuHandlers)
}
```

输出：`endpoint GET /ping main.main.func1 3`

## 8. 结构化日志

结构化日志生成机器可读的 JSON 输出，便于在 ELK/Loki/Datadog 等系统中搜索、过滤和分析。

### 为什么使用结构化日志？

- **可查询的字段** — 按状态码、延迟、用户 ID 过滤
- **一致的格式** — 每条日志结构相同
- **关联性** — 使用请求 ID 跨服务追踪

### 使用 slog（Go 1.21+）

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

func SlogMiddleware(logger *slog.Logger) gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        path := c.Request.URL.Path
        query := c.Request.URL.RawQuery
        c.Next()

        logger.Info("request",
            slog.String("method", c.Request.Method),
            slog.String("path", path),
            slog.String("query", query),
            slog.Int("status", c.Writer.Status()),
            slog.Duration("latency", time.Since(start)),
            slog.String("client_ip", c.ClientIP()),
            slog.Int("body_size", c.Writer.Size()),
        )

        if len(c.Errors) > 0 {
            for _, err := range c.Errors {
                logger.Error("request error", slog.String("error", err.Error()))
            }
        }
    }
}
```

输出示例：

```json
{"time":"2024-01-15T10:30:00Z","level":"INFO","msg":"request","method":"GET","path":"/ping","query":"","status":200,"latency":"125µs","client_ip":"127.0.0.1","body_size":18}
```

### 请求 ID / 关联 ID

```go
func RequestIDMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        requestID := c.GetHeader("X-Request-ID")
        if requestID == "" {
            requestID = uuid.New().String()
        }
        c.Set("request_id", requestID)
        c.Header("X-Request-ID", requestID)
        c.Next()
    }
}
```

### 使用 zerolog

```go
func ZerologMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        c.Next()

        log.Info().
            Str("method", c.Request.Method).
            Str("path", c.Request.URL.Path).
            Int("status", c.Writer.Status()).
            Dur("latency", time.Since(start)).
            Str("client_ip", c.ClientIP()).
            Msg("request")
    }
}
```

### 最佳实践

| 建议 | 说明 |
|------|------|
| 生产用 JSON | 开发用 `TextHandler`，生产用 `JSONHandler` |
| 包含请求 ID | 传播 `X-Request-ID` 头用于分布式追踪 |
| 适当日志级别 | 2xx/3xx 用 Info，4xx 用 Warn，5xx 用 Error |
| 避免敏感数据 | 排除密码、令牌、PII |
| `GIN_MODE=release` | 生产环境禁用默认调试日志 |
