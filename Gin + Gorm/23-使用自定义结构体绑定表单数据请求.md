1. Gin 可以自动将表单数据绑定到嵌套结构体中。当你的数据模型由较小的结构体组成时——无论是嵌入字段、指针字段还是匿名内联结构体——Gin 会遍历结构体层次并将每个 `form` 标签映射到相应的查询参数或表单字段。这对于将复杂表单组织成可重用的子结构非常有用，而不是定义一个包含许多字段的扁平结构体。
2. 示例
```go
type StructA struct {
	FieldA string `form:"field_a"`
}
```
	方式一：
``` go
type StructB struct {
	NestedStruct StructA // 值嵌套，直接内嵌StructA的所有字段
	FieldB string `form:"field_b"`
}
```

	方式二：
``` go
type StructC struct {
	NestedStructPointer *StructA
	FieldC string `form:"field_c"`
}
```
![[Pasted image 20260803161152.png]]

	方式三：
``` go
type StructD struct {  
    NestedAnonyStruct struct {  
       FieldX string `form:"field_x"`  
    }  
    FieldD string `form:"field_d"`  
}
```

3. 路由方式一致，以 StructB 为例：
``` go
r.GET("/getb", func(c *gin.Context) {  
    var B StructB  
    c.Bind(&B)  
    c.JSON(200, gin.H{  
       "a": B.NestedStruct,  
       "b": B.FieldB,  
    })  
})
```
