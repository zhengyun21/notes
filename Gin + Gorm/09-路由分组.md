1. 路由分组允许你将相关路由组织在一个共享的 URL 前缀下。这适用于：
	- **API 版本管理** — 将所有 v1 端点分组到 `/v1` 下，v2 端点分组到 `/v2` 下。
	- **共享中间件** — 将认证、日志记录或限流一次性应用到整组路由，而不是逐个附加到每个路由上。
	- **代码组织** — 在源代码中将相关的处理函数保持在一起。
2. 示例
	1. 基本分组
		``` GO
		g1 := r.Group("/v1")  
		{  
		    g1.GET("/login", login)  
		    g1.GET("/send", send)  
		}
		```
	2. 中间件应用到分组
		``` GO
		func Authenticated() gin.HandlerFunc {  
		    return func(c *gin.Context) {  
		       fmt.Println("前")  
		       c.Next()  // 让你在中间件里写一些「业务处理完之后再执行」的代码：前 → 业务Handler → 后 → 结束
		       fmt.Println("后")  
		    }  
		}
		
		g2 := r.Group("/v2")  
		g2.Use(Authenticated()) // 注册中间件 
		{  
		    g2.GET("/api", func(c *gin.Context) {  
		    c.String(200, "access.")  
		    })  
		}
		```
	3. 嵌套分组
		``` GO
		router := gin.Default()
		api := router.Group("/api")
		{		
			// /api/v1
			v1 := api.Group("/v1")		
			{		
				// /api/v1/users		
				users := v1.Group("/users")		
				users.GET("/", listUsers)		
				users.GET("/:id", getUser)		
				// /api/v1/posts		
				posts := v1.Group("/posts")		
				posts.GET("/", listPosts)		
				posts.GET("/:id", getPost)
			}
		}
		```
	4. 如何中断请求
	**如果你想让中间件拦截请求、不走到业务处理函数，不是靠不写 `c.Next()`，而是：**
```go
func AuthMiddleware(c *gin.Context) {
    token := c.GetHeader("Token")
    if token == "" {
        c.String(401, "未登录")
        c.Abort()   // ← 用这个才能真正中断
        return
    }
}
```
**`c.Abort()` 才是「停止继续执行后续 handler」的开关。不写 `c.Next()` 但正常 return，Gin 还是会继续的。**
