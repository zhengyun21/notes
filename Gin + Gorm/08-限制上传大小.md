1. 使用 `http.MaxBytesReader` 严格限制上传文件的最大大小。当超出限制时，读取器会返回错误，你可以使用 `413 Request Entity Too Large` 状态码进行响应。这对于防止客户端发送超大文件以耗尽服务器内存或磁盘空间的拒绝服务攻击非常重要。
2. 示例
	1. ``` go
		r.POST("/upload/limit", func(c *gin.Context) { 
			// 这行是核心 - 限制请求体大小 
			c.Request.Body = http.MaxBytesReader(c.Writer, c.Request.Body, 1<<20) 
			// 后面跟普通单文件上传一样 
			file, err := c.FormFile("file") if err != nil {  
				c.String(http.StatusRequestEntityTooLarge, "file too large (max: 1MB)")
			    return 
			} 
		    dst := filepath.Join("./test-files/", filepath.Base(file.Filename))
		    c.SaveUploadedFile(file, dst) 
		    c.String(http.StatusOK, "'%s' uploaded!", file.Filename) 
		})
	   ```
