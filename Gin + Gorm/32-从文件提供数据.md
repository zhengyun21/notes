1. go提供了三种方式读取文件：
	1. **`c.File(path)`** — 从本地文件系统提供文件。内容类型会自动检测。当你在编译时已知确切的文件路径或已验证过路径时使用。
	2. **`c.FileFromFS(path, fs)`** — 从 `http.FileSystem` 接口提供文件。适用于从嵌入式文件系统（`embed.FS`）、自定义存储后端提供文件，或当你想限制对特定目录树的访问时。
	3. **`c.FileAttachment(path, filename)`** — 通过设置 `Content-Disposition: attachment` 头将文件作为 **下载** 提供。浏览器会提示用户使用你提供的文件名保存文件，而不管磁盘上的原始文件名。
2. 示例
``` go
r.GET("/local/file", func(c *gin.Context) {  
    c.File("local/file.go")  // 输出磁盘上的文件
})  
  
fs := http.Dir("./assets")  // 读取磁盘上的路径
r.GET("/fs/file", func(c *gin.Context) {  
    c.FileFromFS("fs/file.go", fs)  
	//                └── filepath：相对于 fs 的子路径
})  
  
r.GET("/download", func(c *gin.Context) {  
    c.FileAttachment("local/report-2024-q1.xlsx", "quarterly-report.xlsx") // 访问接口后会触发下载文件操作 
})
```
