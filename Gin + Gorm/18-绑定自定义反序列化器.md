1. **自定义绑定反序列化器**，说白了就是：**Gin 从 HTTP 请求里拿到的是字符串，但你想把它转成自己定义的类型，并且转换规则由你说了算。**
2. 默认情况下，Gin 能把字符串转成 `int`、`bool`、`time.Time` 等常见类型。但如果你自定义了一个类型（比如 `Birthday`），Gin 不知道该怎么把字符串 `"2000-01-01"` 填进去。这时候就需要你告诉 Gin：「这个类型怎么从字符串构造出来」。
3. 方式一
	1. 实现 `encoding.TextUnmarshaler`（Go 标准库接口）
	2. 示例
		```go
		type Birthday string 
		// 实现标准库的 UnmarshalText 接口 
		func (b *Birthday) UnmarshalText(text []byte) error { 
			*b = Birthday(strings.Replace(string(text), "-", "/", -1)) 
			return nil 
		}
		// 然后在 struct 标签里加 `parser=encoding.TextUnmarshaler`：
		Birthday Birthday `form:"birthday,parser=encoding.TextUnmarshaler"`
		// 效果：用户传 `2000-01-01`，自动变成 `2000/01/01`。
		```
4. 方式二
	1. 实现 `BindUnmarshaler`（Gin 专属接口）
	2. 示例
```go
	type Birthday string // 实现 Gin 的 UnmarshalParam 接口 
	func (b *Birthday) UnmarshalParam(param string) error { 
		*b = Birthday(strings.Replace(param, "-", "/", -1)) 
		return nil 
	}
	// 这个**不需要**在标签里加 `parser=...`，Gin 会自动检测
	Birthday Birthday `form:"birthday"`
```
5. 别想着「我要实现接口」，改成想「我要给这个类型加个方法」。加完之后，只要方法签名匹配，接口自动就实现了。（go隐式实现）
6. 你不需要主动去「写接口」。大多数时候是**你定义的类型恰好满足某个现有接口**（比如 `TextUnmarshaler`、`Stringer`、`error`），然后框架（Gin）或标准库会自动调用你的方法。
