1. Gin 的表单绑定通过 `form` 结构体标签中的 `default` 选项支持默认值，即使前端没有传值。
	- 将默认值放在表单键之后：`form:"name,default=William"`。
	- 对于集合，使用 `collection_format:"multi|csv|ssv|tsv|pipes"` 指定如何拆分值。
	- 对于 `multi` 和 `csv`，在默认值中使用分号分隔值（例如 `default=1;2;3`）。Gin 会在内部将其转换为逗号，以保持标签解析器的明确性。
	- 对于 `ssv`（空格）、`tsv`（制表符tab）和 `pipes`（|），在默认值中使用自然分隔符。
		- **csv** — Comma-Separated Values（逗号分隔值）
		- **ssv** — Space-Separated Values（空格分隔值）
		- **tsv** — Tab-Separated Values（制表符分隔值）
	- 只有当你需要 **非逗号分隔** 时才需要写，比如：
		- `collection_format:"ssv"` → 空格分隔：`a b c`
		- `collection_format:"tsv"` → Tab 分隔
		- `collection_format:"multi"` → 多个同名参数：`?a=1&a=2&a=3`
		- `collection_format:"pipes"` → 竖线分隔：`a|b|c`
	- 下面 等价：
		- Friends [ ]string `form:"friends,default=Will;Bill"` 
		- Friends [ ]string `form:"friends,default=Will;Bill" collection_format:"csv"`
2. 示例
``` go
type Person2 struct {  
    Name     string    `form:"name,default=liming"`  
    Age      int       `form:"age,default=67"`  
    Friends  []string  `form:"friends,default=lisi;zhangsan"`
    Family   [2]string `form:"family,default=mom dad" collection_format:"ssv"`  
    LapTimes [3]int    `form:"lapTimes,default=1;2;3" collection_format:"csv"` 
}

r.POST("/person2", func(c *gin.Context) {  
    var person Person2  
    err := c.ShouldBind(&person)  
    log.Printf("Name: %s  Age: %d  Friends: %v  Family: %v  LapTimes: %v", person.Name, person.Age, person.Friends, person.Family, person.LapTimes)  
    if err != nil {  
       c.JSON(http.StatusBadRequest, gin.H{  
          "error": err.Error(),  
       })  
       return  
    }  
    c.JSON(200, gin.H{  
       "message": " ❤️ access!",  
    })  
})
```
