1. 全称 Domain Name System
2. 原理：DNS解析将域名翻译成计算机识别的 ip地址，计算机本地或者服务器会记录域名与其对应的 ip地址。
3. 常见故障：解析配置错误、域名状态异常、修改DNS服务器、修改域名解析记录、域名服务器故障、DNS劫持等
4. 解决方案：
	1. **解析配置错误**
		1. 常见出错情况：
			1. 手动输出ip或者url出错
				1. 复制粘贴解决出错
			2. dns服务器出现挟持或者故障
				1. 更换dns服务器例如8.8.8.8 (原理：**通过手动指定一个可信的第三方DNS服务器，让你的电脑完全无视运营商提供的DNS，直接向可信的“翻译官”寻求帮助，从而获得正确、未被篡改的IP地址，最终成功访问目标网站。**)
			3. dns缓存导致解析失败（为提高解析速度，系统会缓存一段时间的访问记录，但是如果域名的解析记录发生变更，或者dns缓存被人修改，就会出现解析错误。）
				1. 方法：“开始－运行－输入CMD”，执行 ipconfig/flushdns 命令，当出现“successfully flushed the dns resolver cache”的提示时就说明当前计算机的缓存信息已经被成功清除。接下来所有的DNS缓存都会重新加载。
		2. 域名状态异常
			1. 常见出错情况：
				1. **注册信息问题导致的异常**
				2. **过期与续费问题**
				3. **DNS解析问题**
				4. **安全相关状态**
			2. 预防措施
				1. 为了避免域名状态异常的发生，网站运营者还可以采取一些预防措施：
				2. 定期检查域名状态：使用域名管理工具定期检查域名状态，及时发现并解决问题。
				3. 设置自动续费：为了避免域名过期，可以设置自动续费功能，确保域名在到期前得到续费。
				4. 加强域名安全管理：确保域名注册信息的安全性和准确性，避免未经授权的更改或盗用。
				5. 选择可靠的DNS提供商：选择稳定、可靠的DNS提供商，确保域名解析的稳定性和安全性。
		3. **DNS被劫持**
			1. 具体表现：操作系统通过缓存ip与dns的对应关系来提高请求速度，攻击者通过修改dns和ip的对应关系，在你请求后路由到攻击者的网站上，例如当你安装了不知名病毒软件，软件会在后台偷偷修改dns与ip的对应关系来发动攻击。
			2. 如何检测 DNS 劫持
				1. 对网络进行 ping ：`ping` 可疑域名时，重点不是“有没有 IP”，而是“IP 对不对”。解析出 IP 且与可信结果不符 → 可能被劫持；解析不出 IP → 说明解析失败，不能反推为未被劫持。
				2. 检查路由器：攻击者可以使用恶意软件访问路由器的管理页面。进入后，他们可以更改 DNS 设置，以便路由器使用攻击者管理的服务器。要检查此类攻击，只需转到路由器的管理页面并检查其 DNS 设置。
			3. DNS 挟持类型
				1. **本地 DNS 劫持**：如病毒软件
				2. **使用路由器劫持 DNS**：被运营商预置恶意广告或者被入侵攻击
				3. **中间人 （MITM） 攻击**：例如公共热点环境有人拦截了你的请求，把你路由到恶意网址
				4. **恶意 DNS 服务器**
