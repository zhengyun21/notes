# Golang 由易到难源码阅读学习大纲 — 设计文档

## 一、项目背景

为 Golang 学习者提供一份系统化的源码阅读学习路线图，通过阅读高质量开源项目来学习 Go 语法特性、设计模式、架构思想和工程化实践。

## 二、目标读者（全阶段覆盖）

- **Go 语言初学者**：刚学完 Go 基础语法，想通过阅读源码来巩固和提升
- **有其他语言经验的 Go 新手**：有 Java/Python 等经验，刚转 Go，想快速理解 Go 的项目设计范式
- **有一定 Go 经验想深入**：已经写过一些 Go 代码，想学习优秀开源项目的架构和设计思想

## 三、学习维度（全覆盖）

1. 语法特性精讲：接口、goroutine、channel、defer、error 等
2. 设计模式/架构思想：选项模式、函数选项、并发模式、中间件模式等
3. 标准库深入：Go 标准库的设计哲学和关键实现
4. 项目工程化实践：目录结构、依赖管理、测试、CI/CD、错误处理规范等

## 四、组织结构：按难度递进（五阶段）

### 阶段 0：准备篇
- 环境搭建、语法速览、工具准备、读源码方法论

### 阶段 1：入门篇
- 推荐项目：`jmoiron/sqlx`、`codingo/Interpreter`
- 核心：基础语法巩固 + 小项目结构阅读

### 阶段 2：初级篇
- 推荐项目：`gin-gonic/gin`、`sirupsen/logrus`、`fatih/color`
- 核心：并发模型 + 设计模式

### 阶段 3：中级篇
- 推荐项目：`prometheus/prometheus`、`etcd-io/etcd`、`golang-migrate/migrate`
- 核心：系统架构 + 工程化实践

### 阶段 4：高级篇
- 推荐项目：`golang/go` 标准库、`valyala/fasthttp`、`cilium/ebpf`
- 核心：底层原理 + 性能优化

## 五、每个阶段的统一结构

1. **阶段目标**：读完后应该达到什么水平
2. **推荐项目**：每个项目包含简介、核心知识点、阅读路线、重点代码、思考问题
3. **核心知识点精讲**：该阶段的关键语法/模式单独讲解
4. **阶段检验**：如何确认自己已经掌握

## 六、输出格式

- 单个 Markdown 文件：`README.md`（位于项目根目录）

## 七、实施计划

1. 创建根目录 `README.md`
2. 按五阶段结构编写完整大纲内容
3. 确保每个项目都有：简介、为什么选它、核心知识点、阅读路线、重点代码、思考问题
4. 确保每个阶段都有：阶段目标、知识点精讲、阶段检验
